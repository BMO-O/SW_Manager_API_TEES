Filtros:

curl -i -X GET "http://localhost:3333/api/v1/characters?classe="

ESPERADO 200

Filtrar por id:

curl -i --request GET \
  --url http://localhost:3333/api/v1/characters/1

ESPERADO 200

Atualizar personagens:

curl -i --request PUT \
  --url http://localhost:3333/api/v1/characters/1 \
  --header 'Content-Type: application/json' \
  --data '{
    "nome": "Luke Skywalker (Mestre Jedi)",
    "classes": ["Jedi"],
    "planetaNatal": "Ahch-To"
  }'

ESPERADO 200

Remover personagens:

curl -i --request DELETE \
  --url http://localhost:3333/api/v1/characters/1

ESPERADO 204

Consultar Estatisticas:

curl --request GET \
  --url http://localhost:3333/api/v1/characters/stats

ESPERADO 200
